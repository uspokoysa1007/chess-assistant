# ♟️ Chess Assistant (Шахматный Помощник)

> Мощное и плавное браузерное расширение для анализа партий и визуальных подсказок в реальном времени на **Chess.com** и **Lichess.org**.

## 🌟 Главные возможности

* 🏹 **Умные визуальные стрелки:**
  * Отображение 1 лучшего хода или сразу 3 вариантов (чёрная / серая / белая, MultiPV 3).
  * Режим 5 стрелок с рейтинговыми бейджами силы хода (MultiPV 5).
  * Настраиваемый стиль меток клеток: *Квадрат*, *Круг* или *Только стрелка*.
* 🟢 **Умные премувы с проверкой безопасности:**
  * Анализ ответного хода (Ponder), пока противник думает, и полная проверка легальности веток.
  * Мгновенное переключение: как только противник сделал ход, старый премув сбрасывается и рассчитывается твой ход.
* 🛡️ **Легит-режимы (Античит) и естественные паузы:**
  * **Легит 1 (~1750 ELO, ~85% точность)** и **Легит 2 (~1350 ELO, ~75% точность)** — живая игра с безопасными субоптимальными ходами.
  * Выбор времени «мышления» (от `50 мс` до `5 с`) с небольшим случайным разбросом.
* 📊 **Шкала преимущества (Eval Bar):**
  * Динамический баланс сил белых и чёрных, единая шкала и согласованные знаки оценок на стрелках и в логе.
* ⚡ **Режимы скорости под любой контроль времени:**
  * ⚡ **Пуля (50–150 мс)** — мгновенная реакция для быстрых партий.
  * 🎯 **Блиц (~0.5 сек)** — баланс между скоростью и глубиной.
  * 🧠 **Рапид** — глубокий позиционный анализ.
  * 👑 **Ультра (до 26 ходов, ~7 сек)** — максимальная глубина полного движка (на ПК).
* 🌐 **Поддержка двух языков (RU / EN):**
  * Мгновенное переключение интерфейса между **Русским 🇷🇺** и **English 🇬🇧** прямо в меню настроек.
* ⌨️ **Горячие клавиши и удобство в игре:**
  * `H` / `Р` — быстро скрыть или показать подсказки; `R` / `К` — принудительно обновить расчёт позиции.
  * Стрелки **не исчезают**, пока ты держишь или перетаскиваешь фигуру.
  * Плавающий фиолетовый виджет запоминает свою позицию на экране и сворачивается в компактную кнопку `[ ♟️ + ]`.

## 📱 Две версии: ПК и Смартфон

Проект оптимизирован сразу под две платформы:

| Параметр | 💻 Версия для ПК (`chess-assistant.xpi`) | 📱 Версия для Телефона (`chess-assistant_phone.xpi`) |
| :--- | :--- | :--- |
| **Движок** | Stockfish 19 Full NNUE (~4050 ELO) | Stockfish 19 Lite WASM (~3650 ELO) |
| **Вес пакета** | ~75 МБ (полные нейросети NNUE) | **1.2 МБ** (ультра-лёгкий WebAssembly) |
| **Потоки** | Многопоточный расчёт | 1 поток (защита от нагрева батареи смартфона) |
| **Интерфейс** | Расширенный виджет с выбором 1 / 3 / 5 стрелок | Сенсорный виджет и 1 чёткая стрелка |
| **Холст** | Высокое разрешение (DPR 2.0+) с тенями | DPR 1.0 без теней для плавных 60–120 FPS |

## 🚀 Установка

### 💻 На компьютере (Waterfox / Firefox / LibreWolf)
1. Скачай файл [chess-assistant.xpi](https://github.com/uspokoysa1007/chess-assistant/releases/latest/download/chess-assistant.xpi) (или собери локально в `chess-assistant/chess-assistant.xpi`).
2. В браузере открой `about:addons` (или нажми `Ctrl + Shift + A`).
3. Нажми на значок шестерёнки ⚙️ в правом верхнем углу ➔ **«Установить дополнение из файла…»** (Install Add-on From File).
4. Выбери скачанный `.xpi` и подтверди установку.
5. Заходи на [Chess.com](https://www.chess.com) или [Lichess.org](https://lichess.org) — виджет появится автоматически!

### 📱 На смартфоне (Android)
1. Установи браузер **Waterfox** или **Firefox Nightly** из Google Play / официального сайта.
2. Скачай файл [chess-assistant_phone.xpi](https://bygemini.chess-assistants.workers.dev/downloads/chess-assistant_phone.xpi) (при локальной сборке он лежит в `chess-assistant_phone/chess-assistant_phone.xpi`).
3. В браузере нажми меню (три точки) ➔ **«Дополнения»** ➔ значок шестерёнки ⚙️ ➔ **«Установить дополнение из файла»**.
4. Выбери `.xpi` файл. Готово!

## 🛠️ Сборка проекта

Для сборки расширений требуется [Node.js](https://nodejs.org/):

```bash
# Сборка версии для ПК
node chess-assistant/build.js

# Сборка облегчённой версии для смартфонов (автоматически обновляет файл на сайте)
node chess-assistant/build-phone.js
```

На Windows также можно просто запустить `build-all.bat` для сборки обеих версий сразу.
